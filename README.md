# From Paws to Flukes — Whale Evolution

A 2D browser game about whale evolution. Start as a land-dwelling *Pakicetus* and evolve through *Ambulocetus* and *Kutchicetus* into the fully aquatic *Dorudon*.

Everything is in a single `index.html` file (HTML5 Canvas + JavaScript), with no build step or external assets.

## Play

Open `index.html` in a browser, or play the hosted version on GitHub Pages.

## Controls

- **Move:** WASD / arrow keys, or hold the mouse / touch
- **Pause:** P or Esc
- **Continue:** Enter or Space

Eat prey to fill the evolution bar, avoid predators, and watch your oxygen in deep water.
